MI AI VIDEO - PROYECTO ANDROID v0.1

IMPORTANTE:
Esta primera entrega es el proyecto base de Android: interfaz, selector de modo,
campo de prompt, selector de imagen y configuración 720p vertical. TODAVÍA NO
GENERA VIDEOS. La conexión con un proveedor de IA se implementará después de
probar cuál ofrece acceso gratuito y permite el uso desde una app.

CÓMO OBTENER EL APK SIN ANDROID STUDIO:
1. Crea o abre un repositorio en GitHub.
2. Sube el contenido de esta carpeta a la raíz del repositorio.
3. En GitHub, abre la pestaña Actions.
4. Ejecuta "Build Android APK" con Run workflow, o haz push a main/master.
5. Cuando termine, abre la ejecución y descarga el artefacto
   "MI-AI-VIDEO-debug".
6. Dentro encontrarás app-debug.apk para instalar en tu Android.

REQUISITOS DEL PROYECTO:
- Android Gradle Plugin 8.7.3
- Gradle 8.9
- Java 17
- Android SDK 35
- minSdk 23

No pongas claves API en el código ni compartas claves privadas en GitHub.
La siguiente fase será integrar un motor real y gestionar las credenciales con
seguridad. No se promete generación ilimitada ni gratuita permanente: depende
de los límites de cada proveedor.
